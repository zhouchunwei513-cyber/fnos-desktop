feat(titlebar): 磨砂/纯色两种并列效果，两套参数各自独立（v3.0.78）

背景：原「磨砂」是 CSS backdrop-filter + 噪点 + 白高光，只能模糊页面自身，透不出桌面，
不像 iOS 系统材质。按要求改为「磨砂 / 纯色」二选一互斥，两套参数分开存、各自记忆。

一、关键实测（Windows 10.0.26200 / Electron 44）—— 决定技术路线
   - transparent:false + backgroundMaterial:'acrylic'：磨砂生效（背后内容强模糊），
     但它与本项目必保的 20px 自定义圆角冲突；SetWindowRgn(CreateRoundRectRgn) 裁不掉
     DWM 磨砂层（左右半屏实验锐度 11.9 vs 12.3，无差异），圆角仍是直角。
   - transparent:true + acrylic：无效（深灰不透明）。
   - transparent:true + SetWindowCompositionAttribute(ACCENT_ENABLE_ACRYLICBLURBEHIND)：
     无效（红 tint 不上色，截图像素无变化）。
   -> 结论：原生 acrylic 与「透明窗 + 自定义圆角」不可兼得。

二、采用方案：保圆角，磨砂改「主进程实时抓屏 + 渲染层自绘模糊」
   - 新增 titlebar-frost.js：desktopCapturer 抓主屏 480px 缩略图（JPEG q58），
     抓取期间 win.setContentProtection(true)（WDA_EXCLUDEFROMCAPTURE）把自己从画面里排除，
     finally 立刻恢复。探针实测：只给主窗设即可，webview 的 OOPIF guest（独立 HWND）
     随主窗一起被排除（窗口区域红色占比 100% -> 0%，背后真实内容 28.0 vs 屏幕 28.3）。
   - 采样节奏：move/resize/show/focus 后 ACTIVE_MS=240ms；静止 IDLE_MS=6000ms。
     实测 desktopCapturer.getSources 单次约 300ms 且与缩略图尺寸无关（480/320/240 都是 270~360ms），
     所以静止期拉长只为降低「抓取期间窗口不可被截图」的干扰：
     改前 affinity 采样 41:39（近半数时间不可截图），改后 68:12。
     另加 tick 兜底：若窗口仍停在排除状态而当前未在抓取，强制复位。
   - titlebar-inject.js：磨砂分支新增 #fnos-tb-frost-clip > #fnos-tb-frost
     （inset -72px、filter blur(18px) saturate(150%)），背景按整屏坐标对齐：
     backgroundSize = sw px×sh px、backgroundPosition = (72-wx),(72-wy)。
     实测抓屏图与屏幕同位置像素严格对齐（窗口外区域 28.3 vs 28.0），
     标题栏取色随窗口移动而变化（71,69,67 -> 88,83,80）。
   - 内嵌 bar（buildEmbed，收不到主窗抓屏 IPC）回退为「淡色 + backdrop-filter 模糊页面内容」，
     避免变成没有背景的半透明白雾。

三、纯色：完全不透 + 可选 1px 分隔线 + 无内高光
   - 实测配置 #101426，屏幕取色 (16.4,20.3,38.2)，与配置值一致。

四、参数模型（两套独立、各自记忆）
   - 磨砂：tintColor + tintAlpha 2~35
   - 纯色：solidColor + solidAlpha 90~100 + divider
   - 设置页同一滑杆按材质切范围与量纲，标签「玻璃浓度」/「纯色浓度」；
     颜色按材质分流；删除「磨砂强度」「磨砂高光」，新增分隔线开关（仅纯色显示）。
   - main.js 全链路 5 字段：DEFAULT_SETTINGS / loadSettings / preview-titlebar /
     set-ui-options（解析+落盘+缓存）/ __titlebarPayload / settings:get-titlebar /
     settings-preload.js 白名单（v3.0.70 曾因 preload 白名单吞字段导致保存无效）。

五、效果
   - 磨砂：透出桌面、模糊、极淡白染色（默认 10%）、固定 1px 内高光、1px 白描边；
     标题栏圆角、内容区不透明、皮肤体系均不受影响（未窗口透明化，未改圆角逻辑）。
   - 纯色：不透明实色 + 1px 分隔线。
   - 因为不用系统 acrylic，Windows 10 也能用磨砂，无需降级置灰。
