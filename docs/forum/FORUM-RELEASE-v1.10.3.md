## 📌 v1.10.3（2026-08-21）

作者根据论坛反馈集中修复的小版本，建议所有用户更新。

### 🐛 修复

1. **下载进度窗口关闭即取消下载** — 点保存后，系统「另存为」对话框自动消失，下载进度窗口可随时关闭（最小化到后台），**下载任务继续进行**，完成后自动弹出并可在托盘右键菜单「正在下载」中随时找回。
2. **检查更新两种提示不显示** — 已修复：
   - 当前已是最新版 → 弹窗提示「已是最新版本」
   - 发现新版本 → 弹窗显示版本号和更新内容，点击「前往下载」自动打开 GitHub Release 页面
3. **设置窗口无法滚动、全屏看不到全部内容** — 窗口尺寸增大到 780×860、可自由调整大小，整页支持纵向滚动，所有设置项都能完整显示。
4. **「隐私设置」改名并移到一级菜单** — 顶部菜单栏「文件/编辑/视图」后新增一级菜单 **「设置」**（快捷键 `Ctrl + ,`），不再藏在文件子菜单里。
5. **启动密码锁屏只显示密码输入框** — 移除了「修改 / 取消启动密码」入口（该功能仍在设置窗口中可用），锁屏页保持极简，只保留密码框、解锁按钮和显示/隐藏密码的小眼睛。

### ⚡ 性能优化

根据最新 Electron / Chromium 性能文档，补充以下启动开关：

- 禁用 `BackForwardCache`、`GlobalMediaControls`、`MediaRouter`、`PrivacySandbox`、`DialMediaRouteProvider` 等不使用的功能，启动更快、内存占用更低；
- 启用 `GpuMemoryBufferCompositorResources`、`ScrollPredictorSmoothness`、`RawDraw`，滚动更顺滑、合成更少抖动；
- 禁用组件自动更新、域名可靠性上报、Hang Monitor、IPC 洪泛保护、打印预览等后台服务；
- 自动播放策略放开（飞牛影视进入播放页无需再点一次）；
- 保持已有：QUIC、并行下载、100 MB 磁盘缓存、512 MB V8 堆上限、GPU 光栅化、零拷贝、ARM64 自动降级软解。

### 🎨 图标与 Logo

- 程序图标（任务栏、EXE、安装包、快捷方式、托盘）、登录页、锁屏页、设置页、帮助页的 LOGO **全部更换为飞牛 fnOS 官方 LOGO**；
- `icon.ico` **内嵌 16 / 20 / 24 / 32 / 40 / 48 / 64 / 96 / 128 / 256 十种尺寸**，全部为 32 位透明 PNG，Windows 资源管理器、任务栏、Alt+Tab、快捷方式均可清晰渲染；
- 安装包与 EXE 数字图标一致，不再有第三方图标。

## 📌 v1.10.2（2026-08-21）

- ✅ **MPV 真正内置**：安装包自带 `mpv.exe`（GPL 开源，约 114 MB），无需再让用户运行时下载；菜单「视图 → 用 MPV 打开当前视频（硬解）」直接调用电脑显卡解码，4K / HDR 更流畅，CPU 占用更低。
- ✅ **下载流程修复**：点下载后先弹系统「另存为」对话框，**选择保存位置后才开始下载**，不会预先偷偷写入；进度窗口实时显示文件名、进度条、百分比、**下载速度（KB/s、MB/s 自动切换）**、已下载 / 总大小。
- ✅ **检查更新完善**：帮助菜单新增「检查更新…」，请求 GitHub Releases API 比对最新 tag，有新版时弹窗显示版本号和更新内容，点击即可打开下载页；已是最新版时也会明确提示。
- ✅ **性能再优化**：启用 QUIC、并行下载、100 MB 磁盘缓存、512 MB V8 堆上限，页面切换和大文件列表明显更快。
- ✅ 删除了调用外部播放器（PotPlayer / VLC）的入口，统一走内置 MPV。

## 📌 v1.10.0（2026-08-20）

### 🌟 重大更新

1. **Windows 7 支持**：基于 Electron 22（Chromium 108，最后一个支持 Win7 的主版本）打包，Win7 SP1 x64 可正常安装运行。
2. **直播跨域修复**：自动注入 CORS 响应头，等效于飞牛社区推荐的 KNAS 浏览器插件，飞牛影视的直播频道可直接在客户端内观看，不再白屏。
3. **下载进度条**：从 NAS 下载文件到本地时，实时显示进度、速度、已下载 / 总大小，完成后一键打开所在文件夹。
4. **URL 重写规则**：设置中可把内网地址（如 `http://192.168.1.10:5666`）自动替换成外网地址（如 `https://nas.example.com`），方便外网访问时点应用卡片自动跳外网。
5. **内置 MPV 硬解**（v1.10.2 起改为安装包内置）：视图菜单一键用 MPV 打开当前视频，调用显卡硬解，CPU 占用更低、4K HDR 更流畅。
6. **检查更新**：帮助菜单 → 检查更新，一键跳转 GitHub Release 下载新版。
7. **启动密码锁屏玻璃化**：启动密码界面改为真正的透明玻璃效果，内容完整显示，不再有黑底或裁切。
8. **绿屏 / 花屏修复**：移除导致 ARM64 / 集显设备绿屏的 COEP / CORP 头，并伪装 User-Agent 为桌面 Chrome，飞牛音乐、飞牛影视登录后不再绿屏。
9. **OAuth 授权修复**：飞牛影视等用到「使用 NAS 账号授权」的应用，弹窗现在在客户端内打开，授权后自动回跳，不再无反应或循环登录页。
10. **菜单栏自动隐藏**：设置中开启后，菜单栏平时隐藏，按 `Alt` 临时呼出，最大化时更清爽。
11. **玻璃标题栏（实验性）**：设置中可开启 Windows 11 Mica/Acrylic 风格玻璃标题栏，默认关闭，不影响现有功能。
12. **主题色自定义**：内置蓝、青、紫、粉、绿、橙 6 种标题栏配色。
13. **SECURITY.md**：完整的安全审查文档，明确数据保存位置、加密方式、CORS 注入范围、第三方依赖清单。

### 🔒 安全

- 所有设置和登录信息使用 Windows DPAPI 加密保存在 `%APPDATA%\FNOS`；
- 启动密码使用 `scrypt` + 随机盐哈希，**不保存明文**；
- 每个服务器使用独立的 `persist:nas-<hash>` 会话分区，Cookie / 缓存完全隔离。

## ⚠️ 关于「Electron 套壳」的说明

FNOS Desktop 确实是基于 Electron 的定制化 Chromium 外壳，但它在浏览器之外做了以下工作：

- 多服务器独立登录态隔离 + DPAPI 加密；
- 启动密码、全局快捷键、一键隐藏 / 锁定；
- 直播 CORS 跨域修复（等效 KNAS 插件）；
- 内置 MPV 显卡硬解；
- OAuth 弹窗内部接管；
- ARM / 集显设备绿屏修复；
- URL 重写、下载进度、玻璃标题栏、主题色等。

不需要这些功能的用户，直接用浏览器打开 fnOS 地址即可，完全够用。
