# FNOS 桌面客户端 v1.10.4 更新公告

> 飞牛私有云的非官方 Windows 桌面客户端，基于 Electron 22 打包，内核 Chromium 108，原生支持 **Windows 7 SP1 x64 及以上** 系统。
>
> 开源地址：<https://github.com/zhouchunwei513-cyber/fnos-desktop>
> 下载地址：<https://github.com/zhouchunwei513-cyber/fnos-desktop/releases/latest>

## 📦 本次更新（v1.10.4 · 小版本修复）

本次更新集中处理作者内测与早期用户反馈的 **下载、检查更新、启动锁屏、程序图标** 四类问题，不改动任何原有业务逻辑。

### 1. 下载逻辑修复（重点）

- **下载速度显示异常**：旧版本使用 Electron 内置的瞬时速度接口，在某些网络环境下会出现 “200 MB/s” 的假速度、文件却几乎不动的情况。v1.10.4 改为 **3 秒滑动窗口手动计算平均速度**，单位自动在 `B/s`、`KB/s`、`MB/s` 之间切换，数值真实稳定。
- **新增剩余时间（ETA）**：下载进度窗在速度右侧实时显示 “剩余 X 分 Y 秒”，大文件下载体验更直观。
- **进度 UI 节流**：界面每 250 ms 刷新一次，避免下载高频回调导致界面卡顿。
- **关闭进度窗不再取消下载**：点关闭 / 点「后台运行」都只是隐藏窗口，下载继续在后台进行；系统托盘右键菜单可随时找回正在下载的任务；任务全部完成后托盘菜单自动清理。

### 2. 检查更新交互修复

- 点击「帮助 → 检查更新…」后**立即弹出玻璃风格「正在检查更新…」转圈窗**，12 秒超时保护，不再出现 “点了没反应” 的情况。
- 三种结果都有明确反馈：
  - ✅ **已是最新版**：提示当前版本号；
  - 🆕 **发现新版本**：弹窗显示版本号 + Release 更新内容，点击「前往下载」直接打开 GitHub Release 页面；
  - ⚠️ **网络失败**：给出错误原因和 GitHub Release 直达链接，国内网络可配置系统代理后重试。
- 后续只要在 GitHub 发布 Release，老版本用户都会收到提示。

### 3. 启动锁屏极简

- 设置了启动密码的用户，开机锁屏界面**只保留密码输入框 + 解锁按钮**，去掉了 LOGO、标题、副标题、底部版本号和修改密码入口，输入密码回车即可进入。
- 首次设置 / 修改启动密码的功能完整保留在「设置」面板中（文件 → 设置，或按 `Ctrl + ,`）。

### 4. 程序图标 / 快捷方式图标彻底修复

- v1.10.3 曾因 Linux 沙箱打包限制关闭了 electron-builder 的可执行文件图标写入，部分用户安装后 EXE 和桌面快捷方式仍显示 Electron 默认图标。
- v1.10.4 已在 GitHub Actions 的 Windows 构建环境中重新启用图标写入，**EXE、桌面快捷方式、开始菜单、任务栏分组、控制面板卸载项** 统一使用飞牛 LOGO。
- ICO 内嵌 10 种尺寸：`16 / 20 / 24 / 32 / 40 / 48 / 64 / 96 / 128 / 256`，全部 32 位透明 PNG，Windows 资源管理器、任务栏、快捷方式均可正常渲染。
- 新增 `app.setAppUserModelId('com.fnos.client')`，Windows 任务栏通知 / 跳转列表按品牌 AUMID 分组，不会再混入默认 Electron 分组。

> 💡 如果是从 v1.10.3 覆盖安装，Windows 可能因为图标缓存仍显示旧图标，**重启资源管理器或注销重登**即可刷新，无需重装。

### 5. 性能优化

- 关闭渲染进程后台节流，切到后台的视频 / 下载窗口不再被 Chromium 降速。
- 启用 GPU 光栅化、零拷贝、忽略 GPU 黑名单，集显 / 老显卡也能走硬件加速。
- 禁用 MediaRouter / Translate / PrivacySandbox / BackForwardCache / GlobalMediaControls 等非必要组件，减少内存和 CPU 占用。
- 下载进度 250 ms 节流、托盘菜单 1.5 s 节流，高频回调不再卡 UI。

### 6. 帮助文档更新

- 帮助页新增「v1.10.4 更新说明」章节。
- 常见问题补充 Windows 图标缓存刷新方法。

### 7. 安全审查

- 本次新增 / 修改的代码已完成安全自查，详见仓库根目录 `SECURITY.md` 的「v1.10.4 安全自查补充」。
- 所有网络请求仍只发生在用户自己配置的 fnOS 服务器与 GitHub Releases API 之间，无任何第三方上报 / 埋点 / 自动下载。
- `contextIsolation: true`、`nodeIntegration: false`、CSP 策略不变；启动密码继续使用 scrypt + 随机盐 + `timingSafeEqual`。

- 检查更新首版：帮助菜单新增「检查更新…」，调用 GitHub Releases API 比对版本号。

- 多窗口稳定性修复：从飞牛主页打开多个应用时偶发的窗口状态丢失问题。

### v1.10.0（2026-08-18）

- 玻璃锁屏系统：透明毛玻璃锁屏 + 彩虹光带动画，支持启动密码；scrypt 加盐哈希，锁屏窗口屏蔽 F5 / Ctrl+R / ESC / 右键 / Alt+F4。
- 设置面板：图形化设置窗口，可管理启动密码、性能开关、全局快捷键、菜单栏行为。
- 一键隐藏：可设置全局快捷键，一键彻底销毁托盘图标和所有窗口，再次按快捷键恢复。
- 全局快捷键：锁定 / 一键隐藏均可自定义组合键。
- 性能开关：禁用后台节流、GPU 光栅化、零拷贝、忽略 GPU 黑名单等。
- 多服务器 partition 隔离：每个服务器使用独立 `persist:nas-<hash>` partition，Cookie / 缓存 / 登录态物理隔离。
- OAuth 弹窗修复：NAS 账号授权改为客户端内独立窗口，授权完成自动回跳。
- 直播跨域 / 绿屏修复：自动注入 CORS 响应头，移除导致 ARM / 集显绿屏的 COEP/CORP 头。

## ⬇️ 下载与安装

1. 打开 Release 页面：<https://github.com/zhouchunwei513-cyber/fnos-desktop/releases/latest>
2. 下载 `FNOS-Setup-1.10.4.exe`（约 110 MB，x64 安装版）；便携版可选 `FNOS-1.10.4-portable.exe`。
3. 双击运行，按向导安装即可。建议保持默认路径 `%LOCALAPPDATA%\Programs\FNOS`，无需管理员权限。
4. 首次启动输入 fnOS 服务器地址（IP / 域名 / FN ID 均可），在客户端内完成登录。

> 🔒 本程序不上传任何账号、密码、Cookie 或文件内容到第三方，所有数据使用 Windows DPAPI 加密保存在本机。详见仓库 `SECURITY.md`。
