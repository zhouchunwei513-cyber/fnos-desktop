FNOS

私 有 云 桌 面 客 户 端 · 使 用 指 南

软件简介

FNOS 桌面客户端是飞牛私有云（fnOS）的非官方第三方 Windows 桌面端。基于 Electron 22 构建，原生支持 Windows 7 SP1 x64 / Windows 10 / Windows 11，把飞牛 NAS 的文件、相册、影视、Docker 等全部应用收进一个独立客户端，不跳系统浏览器；支持多账号、启动密码、一键隐藏，并内置 MPV 播放器做显卡硬解 4K。

本软件不收集、不上传、不转发任何用户数据；无埋点、无崩溃上报、无静默下载。NAS 登录信息与你设置的启动密码均保存在本机（密码经系统 DPAPI + scrypt 加密）。

快速开始

1
在登录页填写服务器地址

支持三种形式：内网 IP（如 192.168.1.10）、域名加端口（如 nas.example.com:5666），或 FN ID（直接填写，例如 abc123，会自动跳转 fnos.net）。HTTP / HTTPS 均可，自签证书站点会弹确认框。

2
登录飞牛账号

客户端会自动跳转到飞牛 fnOS 的登录页，输入你的 NAS 账号密码。登录成功后登录态会长期保持，下次打开无需重复登录。

3
在客户端内使用全部应用

飞牛桌面上的文件、相册、影视、Docker 等应用点击后都在客户端内打开（每个应用是独立窗口），不会外跳到系统浏览器。

💡 历史地址自动记录。输入框右侧的 ▾ 可查看、切换或删除连接过的服务器，每个服务器的登录状态互相独立。想同时挂多个 NAS，用 文件 → 切换账号 或 设置 → 账号管理。

主窗口与标题栏

  • 标题栏按钮：最左侧 ☰ 打开应用菜单；右侧依次为 — 最小化、□ 最大化 / 还原、✕ 关闭（关闭时会询问「隐藏到托盘」还是「退出程序」）。
  • 拖动与双击：按住标题栏空白处可拖动窗口；双击标题栏 在最大化与还原之间切换。
  • 固定画面比例：主窗口按 45 : 27.65 的画面比例锁定（已扣除标题栏高度），拖任意边缩放时自动保持比例，避免飞牛桌面被拉伸变形。
  • 圆角窗口：窗口四角为圆角（帮助页与偏好设置页与标题栏采用同比例圆角），无系统灰边。
  • 全屏：F11 进入 / 退出全屏，Esc 也可退出全屏（先退全屏，再退最大化）。
  • 页面缩放：Ctrl+= 放大、Ctrl+- 缩小、Ctrl+0 复位，也支持 Ctrl+滚轮。

常用快捷键

Alt+H 返回主页   Alt+← / → 前进后退   Ctrl+, 偏好设置   F5 刷新   F11 全屏   Esc 退出全屏   Ctrl+Shift+P MPV 播放   Ctrl+Shift+C 复制链接

全局快捷键（可在 设置 → 快捷键 自定义，默认为）： Ctrl+Alt+L 锁定 FNOS； Ctrl+Alt+H 一键隐藏 / 呼出。

启动密码 / 自动锁定 / 一键隐藏

  • 在 设置 → 启动密码 中设置（至少 4 位）。密码以 scrypt + 随机盐哈希保存，不保存明文，并经系统 DPAPI 加密。
  • 设置后每次启动 FNOS 会先弹出玻璃锁屏，输入正确密码才能进入。
  • 锁定 FNOS：菜单「文件 → 锁定 FNOS」/ 托盘恢复时需密码 / 全局快捷键 Ctrl+Alt+L（快捷键可改）。
  • 无操作自动锁定：在 设置 → 启动密码 下方可选 1 / 3 / 5 / 10 / 20 / 30 / 60 分钟，键鼠无操作达到时长后自动锁定并隐藏所有窗口；全屏播放视频时不触发。
  • 一键隐藏：所有窗口连同托盘图标一起消失，适合临时遮挡屏幕；再按同一快捷键即可恢复。

忘记启动密码怎么办？

启动密码只存在本机且经 DPAPI 加密，无法找回明文。忘记时按下面步骤清除（只清启动密码，不动 NAS 登录信息）：

  • 1）先完全退出 FNOS（托盘右键 → 退出程序；若停在锁屏，可用任务管理器结束 FNOS 进程）。
  • 2）按 Win+R，输入 %APPDATA%\FNOS 回车。
  • 3）删除该目录下的 settings.json（建议先备份到桌面）。
  • 4）重新打开 FNOS，启动密码即被清除，可进去后在设置里重新设置。
删除 settings.json 会同时重置偏好设置（界面、快捷键、直播、MPV 等）。NAS 登录历史存在 servers.json，不受影响。

开机自启动 · 多账号 · 桌面快捷方式

开机自启动

设置 → 开机自启动 打开后，开机时飞牛在后台托盘常驻（不弹主界面），点桌面快捷方式即可快速打开，不必重新登录。

多账号管理

  • 设置 → 账号管理 可查看所有已登录的 NAS 账号、切换当前账号、点「+ 登录其它账号」新增。
  • 每个账号有独立的持久化会话分区，Cookie 与本地数据分别保存，互不影响。
  • 也可以用 文件 → 切换账号 快速切换（当前账号前有 ● 标记）。

应用桌面快捷方式

  • 设置 → 应用快捷方式创建 列出 NAS 上已安装的应用，可为每个应用创建 Windows 桌面快捷方式；双击快捷方式由主程序代为打开对应应用（依赖主程序登录态）。
  • 可选「打开应用后主程序：隐藏到托盘 / 最小化到任务栏」，应用窗口仍正常显示。
  • 设置 → 图标管理器（FPK API）：填入 FPK 图标管理器地址和端口（默认 18080）并启用后，快捷方式与任务栏图标会优先使用 FPK 中的自定义图标。

下载文件到本地

  • 在飞牛文件应用中点下载后，会弹出客户端的「另存为」对话框，选好位置开始下载。
  • 下载进度窗口实时显示文件名、保存路径、进度条、百分比、下载速度、已下载 / 总大小与剩余时间（ETA）。
  • 点进度窗口的 × 不会取消下载，只是把窗口藏到后台，下载继续。
  • 找回后台下载：菜单「下载 → 下载任务」列出所有正在下载的文件与最近完成的记录；点活跃项调出进度窗口，点已完成项打开文件所在文件夹。
  • 下载完成后会弹系统通知，进度窗口自动关闭；点「打开所在文件夹」可在资源管理器中选中该文件。
  • 取消下载会先本地暂停、等 1.5 秒再安全断开，不会向 NAS 发送删除请求，不影响 NAS 上的原文件。

内置 MPV 播放器（显卡硬解 · 原位播放）

  • 安装包已内置 mpv.exe（GPL 开源），无需另外下载；运行库随应用打包。
  • 自动接管：飞牛影视里遇到网页播放器解不了的视频（HEVC/H.265、10bit、4K、MKV 等），客户端会自动抓取真实视频地址，在页面视频区原位调用内置 MPV 显卡硬解，不弹外部窗口；也可在播放页用 工具 → 用 MPV 嵌入播放当前视频（Ctrl+Shift+P）手动接管；在设置里打开「默认用 MPV 播放」后，飞牛影视的视频会直接交给 MPV，不再等解码失败。
  • 中文界面：MPV 的控制条（OSC）、右键菜单、对话框均为中文。鼠标移到画面底部显示控制条，右键弹出菜单（字幕、音轨、画面、倍速等）。
  • 硬解与缓存：设置 → 兼容性播放器（MPV） 可切换硬件解码（自动 / D3D11VA / DXVA2 / 关闭软解）与网络缓存档位（均衡 32MB·60s / 流畅 128MB·120s（4K 推荐）/ 超大 512MB·300s），还能切换「默认用 MPV 播放（所有视频直接走 MPV）」与「解码失败时自动兜底」两种模式，两个都关掉则只保留手动接管入口。
  • 剧集连播：电视剧用 MPV 播放时，画面底部的 上一集 / 下一集 按钮会跟随网页剧集列表点亮（原生 OSC 单文件播放时恒为灰色），点击即在网页内切集并由 MPV 继续播放；一集播完会自动切到下一集。
  • 长视频自动续播：点播（MKV / 电影）用的是 NAS 的时效签名链接，播久了会过期。MPV 会自动重新取流并从断点续播；拖进度条若定位慢也会自动重新取流并跳到你拖的位置。
  • 全屏铺满整屏：飞牛影视、电视直播进入全屏后，MPV 采用 fullscreen 模式由播放器自己接管窗口尺寸，铺满整个显示器（含任务栏区域），不再出现右侧 / 底部灰边错位。
  • 圆角与关闭：点播窗口四角为 20px 圆角（直播窗右上角圆角）；点 MPV 画面右上角的 × 可关闭播放器回到网页（不会自动重开），换台 / 换片时自动切到新节目。
  • 播放日志：%APPDATA%\FNOS\fnos-mpv.log（HTTP 状态、重定向、断流与重连 / 重新取流记录）。反馈问题时可一并提供。

内置电视直播

  • 工具 → 📺 电视直播（原生播放器） 打开直播窗口，同样使用内置 MPV 内核，支持 4K 高清直播、HLS(m3u8) / FLV 等流，换台即播。
  • 设置 → 直播与播放 可配置：
    • NAS 直播基地址（可填 XTE 网关，如 http://192.168.1.10:34500；留空用当前 NAS）
    • 默认订阅线路：内网 IPv4 / IPv6 DDNS / FRP 中转
    • EPG 节目单地址：XMLTV 的 .xml / .xml.gz，多个用英文逗号分隔；留空自动读直播源 M3U 头里的 x-tvg-url
    • 直播缓冲秒数：0–120 秒（默认 30），网络不稳时加大可减少卡顿
    • 创建桌面快捷方式：为电视直播生成 Windows 桌面快捷方式，双击直达直播窗口（程序已运行时秒开，不经过主界面）
  • 断流自愈：直播长跑遇到运营商断流 / 抖动时 MPV 会自动重连（最多 30 次），播放进程异常也会崩溃自愈续播。
  • 飞牛影视网页内的直播频道同样会自动用 MPV 接管播放。

界面个性化

  • 自动隐藏标题栏：开启后鼠标移到窗口顶部才显示标题栏，按 Alt 也可临时呼出；关闭则标题栏常驻。所有窗口统一生效。
  • 标题栏不透明度：0 为完全透明，数值越大标题栏底色越明显。
  • 标题栏颜色：点击色块打开系统取色器，也可直接输入 #RRGGBB 或 #RRGGBBAA；右侧 Alpha 滑块与不透明度联动。
  • 改完点「保存界面设置」即时生效。

外网访问与 URL 重写

在 设置 → 应用外网地址（URL 重写） 里可以把内网地址自动替换成外网地址。规则格式：内网端口或路径片段 → 外网完整地址，例如：

  • 匹配：http://192.168.1.10:5666
  • 替换为：https://nas.example.com

这样在客户端里点应用卡片时会自动用外网地址打开，适合在外网环境下使用。留空表示不重写。

关于与检查更新

  • 菜单 关于 → 关于 FNOS 打开关于窗口：里面显示当前版本号，并提供 检查更新 按钮。
  • 点「检查更新」会向 GitHub 查询本项目的最新 Release；弹窗里会同时给出 当前版本 与 最新版本 两个版本号：
    • 有新版本：按钮为「前往下载」与「稍后」。点「前往下载」用系统浏览器打开 GitHub Release 页面，由你自行下载安装包并安装（客户端不静默下载、不自动安装）。
    • 已是最新：提示「当前版本：vX / 最新版本：vY / 已是最新版本」。
  • 客户端会跟随系统代理（Clash / v2ray 等的「系统代理」或 TUN 模式）访问 GitHub；若提示连接失败，先确认代理已开启，或稍后重试。

常见问题

连接失败怎么办？

  • IP / 域名方式：确认 NAS 已开机、和电脑在同一网络、端口（默认 5666）正确。
  • FN ID 方式：确认 FN ID 拼写正确，且电脑能访问外网（fnos.net）。
  • HTTPS 自签证书站点：在弹出的证书确认窗口选择继续即可（仅对已知 NAS 来源放行）。

登录状态会失效吗？

不会。每个账号有独立的持久化会话分区，Cookie 与本地数据加密保存在本机；关闭主窗口、隐藏到托盘、切换账号再切回、或重启电脑后再打开，都会自动保持登录。只有在登录页历史列表里主动删除该服务器，或在飞牛页面里主动登出，才会清除对应登录状态。

视频播到一半中断 / 进度条拖不动？

电影 / MKV 走的是 NAS 的时效签名链接，播久了链接会过期。新版内置 MPV 会自动重新取流并从断点续播，拖进度条卡住时也会自动重新取流并跳到目标位置，一般无需操作。若仍异常，可关闭 MPV 后用 工具 → 用 MPV 嵌入播放当前视频 重新接管，并把 fnos-mpv.log 与 fnos-diag.log 一起反馈。直播频道分片实时刷新，不受此影响。

全屏后播放器错位 / 有灰边？

从 v2.17.59 起，全屏改用 MPV 的 fullscreen 模式铺满整屏（含任务栏区域）。若仍看到灰边，请确认已升级到最新版（关于 → 关于 FNOS → 检查更新），并在反馈时附上 fnos-diag.log（其中 mpv.win.mismatch 行会记录实际窗口尺寸）。

绿屏 / 花屏 / 授权无反应？

  • 已移除会导致 ARM / 集显设备绿屏的 COEP / CORP 头，并把 UA 伪装为桌面 Chrome，飞牛音乐、影视登录后不再绿屏。
  • NAS 账号授权（OAuth）改为在客户端内独立窗口打开，授权完成后自动回跳，不再循环登录页。

可以投屏 / 用媒体键吗？

可以。保留了 Chromium 原生 MediaRouter、CastMediaRouteProvider、DialMediaRouteProvider、GlobalMediaControls、HardwareMediaKeyHandling，飞牛影视可投到 Chromecast / DLNA 设备，系统媒体面板和键盘多媒体键可控。

如何彻底退出？

托盘图标右键 → 退出程序。选「隐藏到托盘」时程序仍在后台运行（下载、同步等长任务会继续）。

数据保存在哪里？

设置与登录信息都在 %APPDATA%\FNOS，密码经系统 DPAPI 加密。卸载程序不会删除该目录，重装后登录数据仍在。

桌面 / 开始菜单图标还是旧的？

安装程序会自动调用 SHChangeNotify 与 ie4uinit -show 刷新图标缓存。极少数情况下仍未刷新，可在任务管理器里重启「Windows 资源管理器」，或注销重登一次。

日志与问题反馈

遇到异常时，把下面这些日志一起提供，定位会快很多（均在 %APPDATA%\FNOS）：

fnos-diag.log客户端主诊断日志（窗口几何、全屏状态、MPV 窗口尺寸自校验等）

问题现象建议连同 版本号（本页页脚 / 关于 → 关于 FNOS 里可见）、NAS 系统版本、复现步骤 一起说明。
