v1.10.5 更新说明

  • 修复点下载弹出 2 个保存对话框：同 URL + 同文件名在 1.5 秒内重复触发 will-download 时自动去重；移除了 enable-parallel-downloading 和 max-connections-per-host=32 两个会让部分 NAS 网关认为同一文件发起两次请求的激进开关；will-download 触发后立即 pause() 阻止 Chromium 默认下载落到默认目录。
  • 修复下载进度框布局只显示一部分：窗口从 500×168 调整为 560×200，允许横向拉伸；卡片内部改为 flex 列布局，文件名、保存路径自动省略，底部状态栏 / 按钮组使用 nowrap 防止换行裁切。
  • 修复取消下载可能损坏 NAS 原文件（重大）：① 取消按钮不再立即 item.cancel()（会发 TCP RST，飞牛 NAS 在某些版本下会误清理临时文件，极端情况波及原文件），改为先 pause() 停止接收数据，等 1.5 秒让服务端完成当前 chunk 并正常 EOF，再 cancel()；② 收紧 CORS 拦截器 —— 之前对所有响应都注入 Access-Control-Allow-Origin: * + Allow-Credentials: true（这在规范上是非法组合），且对所有 OPTIONS 请求直接返回 204 空响应，可能干扰飞牛前端的取消下载 / 删除等业务 API；现在只对 m3u8 / ts / mp4 / mkv / flv 等媒体 / 直播流注入 CORS，业务 API 的 OPTIONS 完全透传给 NAS。
  • 修复开了代理仍提示无法连接 GitHub：检查更新请求显式绑定 session.defaultSession，Electron net 会自动读取 Windows 系统代理（Clash / v2ray / Shadowsocks 等只要是"系统代理"或"TUN 模式"都会生效）；超时从 12 秒延长到 25 秒；失败后自动重试 1 次；错误提示中明确告知代理模式要求。
  • 检查更新弹窗统一为透明玻璃风格："正在检查更新…"的转圈弹窗改为和其他提示一致的毛玻璃卡片样式，不再使用自绘的不透明小方块。
  • 快捷方式图标彻底覆盖：NSIS 安装脚本在创建新快捷方式前先删除旧的 .lnk；为 EXE 和快捷方式显式指定 icon index 0；安装完成后调用 SHChangeNotify 通知资源管理器刷新图标缓存；写入 AppUserModelID 与主程序一致，任务栏分组不再使用旧图标缓存。
  • 恢复被误禁用的 Chromium 服务：v1.10.3/v1.10.4 为"性能优化"关闭了 MediaRouter、CastMediaRouteProvider、DialMediaRouteProvider、GlobalMediaControls、HardwareMediaKeyHandling，这些会影响飞牛影视的投屏（Chromecast / DLNA）、系统媒体控制面板、硬件多媒体键等功能。v1.10.5 全部恢复，只保留 Translate、InterestFeedContentSuggestions、PrivacySandbox 等与 NAS 业务无关的开关。
  • 安全审查：CORS 注入范围最小化、下载取消流程不向 NAS 发送任何 DELETE/PUT、检查更新请求不携带 Cookie / 凭据（credentials: 'omit'）、不去解析 GitHub 返回的 HTML（只取 tag_name/name/body/html_url 四个字段）。

提示：如果升级后桌面快捷方式仍显示旧图标，重启资源管理器或注销重登一次即可；这是 Windows 图标缓存机制所致，不是安装包本身的问题。

快速开始

1
在登录页输入服务器地址

支持三种形式：内网 IP（如 192.168.1.10）、域名加端口（如 nas.example.com:5666），或 FN ID（直接填写，例如 abc123，会自动跳转 fnos.net）。

2
点击「登 录」

客户端会自动跳转到飞牛 fnOS 的登录页面，请输入你的飞牛账号密码。登录成功后，客户端会保持登录状态，下次打开无需重复登录。

3
在客户端内使用所有应用

文件、相册、Docker 等所有飞牛应用均在客户端内打开，不会外跳到系统浏览器。每个应用以独立窗口运行，可以通过菜单栏或托盘切换。

💡 历史地址会自动记录。输入框右侧的 ▾ 按钮可查看、切换或删除已连接过的服务器，每个服务器的登录状态独立保存。

菜单栏与快捷键

文件

  • 返回 FNOS 主页：主窗口回到服务器首页，已打开的应用可选择后台运行或关闭
  • 切换窗口：列出所有已打开的应用窗口，快速跳转
  • 切换服务器：返回登录页，可选择历史地址快速切换（已登录服务器的账号密码会自动保持）
  • 锁定 FNOS / 一键隐藏：仅在已设置启动密码时出现

视图

  • 后退 / 前进：页面历史导航
  • 刷新 / 强制刷新：F5 / Ctrl+F5
  • 全屏：F11，按 Esc 退出全屏
  • 缩放：Ctrl + = / - / 0
  • 用 MPV 打开当前视频（硬解）：自动调用内置 MPV 播放器进行显卡硬解

设置（一级菜单）

  • 偏好设置…（Ctrl+,）：打开设置窗口，可配置启动密码、全局快捷键、URL 重写、玻璃标题栏、主题色、菜单栏自动隐藏等

帮助

  • 操作步骤帮助：打开本页
  • 检查更新…：请求 GitHub Releases，提示「已是最新版」或「发现新版本」

常用快捷键

Alt+H 返回主页   Ctrl+Shift+L 切换服务器   Ctrl+, 偏好设置   F5 刷新   F11 全屏   Esc 退出全屏 / 最大化

全局快捷键（在 设置 中可自定义，默认）： Ctrl+Alt+L 锁定 FNOS； Ctrl+Alt+H 一键隐藏（含托盘图标）。

内置 MPV 播放器（显卡硬解）

  • 安装包已内置 mpv.exe（约 114 MB，GPL 开源），无需另外下载。
  • 在飞牛影视播放页打开 视图 → 用 MPV 打开当前视频（硬解），客户端会自动抓取页面上的视频地址并调用 MPV。
  • MPV 直接调用电脑显卡进行硬解，4K / HDR 视频更流畅，CPU 占用更低。
  • 如需手动操作，也可以在系统终端运行："%LOCALAPPDATA%\Programs\FNOS\bin\mpv\mpv.exe" <视频地址>。

启动密码 / 一键锁定 / 一键隐藏

  • 在 设置 → 启动密码 中设置 4 位以上密码。密码使用 scrypt + 随机盐哈希存储，不保存明文，并经系统 DPAPI 加密。
  • 设置后，每次启动 FNOS 会弹出玻璃锁屏，只显示密码输入框，输入正确密码才能进入。
  • 锁定 FNOS：菜单或托盘项 / 全局快捷键 Ctrl+Alt+L。
  • 一键隐藏：所有窗口连同托盘图标一起消失，适合临时遮挡屏幕；再次按同一快捷键即可恢复。

下载文件

  • 在飞牛文件应用中点下载后，会先弹出系统「另存为」对话框，选择保存位置后才开始下载。
  • 下载进度窗口实时显示文件名、进度条、百分比、下载速度、已下载 / 总大小。
  • 关闭进度窗口不会取消下载：下载会继续在后台进行，完成后窗口自动弹出提示。
  • 下载完成后点击「打开所在文件夹」直接定位到文件。

外网访问与 URL 重写

在 设置 → 应用外网地址（URL 重写规则） 中，可以把内网地址自动替换成外网地址。例如：

  • 匹配：http://192.168.1.10:5666
  • 替换为：https://nas.example.com

这样点应用卡片时会自动用外网地址打开，适合在外网环境下使用。

界面个性化

  • 自动隐藏菜单栏（按 Alt 显示）：设置中开启后，菜单栏平时隐藏，按 Alt 临时呼出，最大化时更清爽。
  • 玻璃标题栏（实验性）：默认关闭，开启后使用 Windows 11 Mica/Acrylic 风格的标题栏。不影响任何现有功能，不喜欢可随时关闭。
  • 主题色：内置蓝、青、紫、粉、绿、橙 6 种标题栏配色。

直播 / 绿屏 / 授权问题修复

  • 电视直播跨域：客户端自动注入 CORS 响应头，等效于 KNAS 浏览器插件，飞牛影视的直播频道可直接观看。
  • 绿屏 / 花屏：移除了导致 ARM / 集显设备绿屏的 COEP / CORP 头，并伪装 User-Agent 为桌面 Chrome，飞牛音乐、飞牛影视登录后不再绿屏。
  • NAS 账号授权无反应：所有 OAuth 弹窗改为在客户端内以独立窗口打开，授权完成后自动回跳，不会再循环登录页。
  • Win7 支持：基于 Electron 22（Chromium 108，最后一个支持 Win7 的版本）打包，Win7 SP1 x64 可安装运行。

多窗口与后台运行

  • 在飞牛中打开的每个应用都在独立窗口中运行，可以同时使用多个应用。
  • 点击主窗口关闭按钮时，可选择「隐藏到托盘」（所有窗口继续后台运行，适合下载、同步等长任务）或「退出程序」。

常见问题

连接失败怎么办？

  • IP / 域名方式：确认 NAS 已开机、和电脑在同一网络、端口（默认 5666）正确。
  • FN ID 方式：确认 FN ID 拼写正确，电脑能访问外网（fnos.net）。
  • HTTPS 自签证书站点：在弹出的证书确认窗口选择继续即可。

登录状态会失效吗？

不会。每个服务器都有独立的持久化会话分区，Cookie 和本地数据加密保存在本机；关闭主窗口、隐藏到托盘、切换到其他服务器再切回来、或重启电脑后再次打开，该服务器的飞牛账号都会自动保持登录。只有在登录页历史列表里主动删除该服务器，或在飞牛页面里主动登出，才会清除对应服务器的登录状态。

如何彻底退出？

托盘右键 → 退出，或在文件菜单里选退出。选「隐藏到托盘」程序仍会在后台运行。

数据保存在哪里？

所有设置和登录信息保存在 %APPDATA%\FNOS，使用系统 DPAPI 加密。卸载程序时不会删除此目录，重新安装后登录数据仍在。
