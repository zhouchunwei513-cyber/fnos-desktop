FNOS

私 有 云 桌 面 客 户 端 · 使 用 指 南

快速开始

1
在登录页输入服务器地址

支持三种形式：内网 IP（如 192.168.1.10）、域名加端口（如 nas.example.com:5666），或 FN ID（直接填写，例如 abc123，会自动跳转 fnos.net）。

2
点击「登 录」

客户端会自动跳转到飞牛 fnOS 的登录页面，请输入你的飞牛账号密码。登录成功后，客户端会保持登录状态，下次打开无需重复登录。

3
在客户端内使用所有应用

文件、相册、Docker 等所有飞牛应用均在客户端内打开，不会外跳到系统浏览器。每个应用以独立窗口运行，可以通过菜单栏或托盘切换。

💡 历史地址会自动记录。输入框右侧的 ▾ 按钮可查看、切换或删除已连接过的服务器，每个服务器的登录状态独立保存。

菜单栏与快捷键

文件

  • 返回 FNOS 主页：主窗口回到服务器首页，已打开的应用可选择后台运行或关闭
  • 切换窗口：列出所有已打开的应用窗口，快速跳转
  • 切换服务器：返回登录页，可选择历史地址快速切换（已登录服务器的账号密码会自动保持）

视图

  • 后退 / 前进：页面历史导航
  • 刷新 / 强制刷新：F5 / Ctrl+F5
  • 全屏：F11，按 Esc 退出全屏
  • 缩放：Ctrl + = / - / 0

常用快捷键

Alt+H 返回主页   Ctrl+Shift+L 切换服务器   F5 刷新   F11 全屏   Esc 退出全屏 / 最大化

多窗口与后台运行

  • 在飞牛中打开的每个应用都在独立窗口中运行，可以同时使用多个应用。
  • 点击主窗口关闭按钮时，可选择「隐藏到托盘」（所有窗口继续后台运行，适合下载、同步等长任务）或「退出程序」。
  • 在系统托盘（任务栏右下角）左键单击 FNOS 图标显示所有窗口；右键打开菜单，可切换窗口、检查更新、退出程序。
  • 选择「返回 FNOS 主页」时，如果还有其他应用窗口打开，会让你选择是后台保留还是一并关闭。

常见问题

连接失败怎么办？

  • IP / 域名方式：确认 NAS 已开机、和电脑在同一网络、端口（默认 5666）正确。
  • FN ID 方式：确认 FN ID 拼写正确，电脑能访问外网（fnos.net）。
  • HTTPS 自签证书站点：在弹出的证书确认窗口选择继续即可。

登录状态会失效吗？

不会。每个服务器都有独立的持久化会话分区，Cookie 和本地数据加密保存在本机；关闭主窗口、隐藏到托盘、切换到其他服务器再切回来、或重启电脑后再次打开，该服务器的飞牛账号都会自动保持登录。只有在登录页历史列表里主动删除该服务器，或在飞牛页面里主动登出，才会清除对应服务器的登录状态。

如何彻底退出？

托盘右键 → 退出，或在文件菜单里选退出。选「隐藏到托盘」程序仍会在后台运行。

数据保存在哪里？

所有设置和登录信息保存在 %APPDATA%\FNOS，使用系统 DPAPI 加密。卸载程序时不会删除此目录，重新安装后登录数据仍在。
