FNOS

私 有 云 桌 面 客 户 端 · 使 用 指 南

软件简介

FNOS 桌面客户端是飞牛私有云（fnOS）的非官方第三方 Windows 桌面端。基于 Electron 22 构建，原生支持 Windows 7 SP1 x64 / Windows 10 / Windows 11，把飞牛 NAS 的文件、相册、影视、Docker 等所有应用收纳在一个独立客户端内，不跳系统浏览器，可锁定、可一键隐藏、可用内置 MPV 显卡硬解 4K 视频。

本软件不收集、不上传、不转发任何用户数据；无埋点、无崩溃上报、无静默下载。所有 NAS 密码使用系统 DPAPI + scrypt 加密保存在本机。

快速开始

1
在登录页输入服务器地址

支持三种形式：内网 IP（如 192.168.1.10）、域名加端口（如 nas.example.com:5666），或 FN ID（直接填写，例如 abc123，会自动跳转 fnos.net）。

2
点击「登 录」

客户端会自动跳转到飞牛 fnOS 的登录页面，请输入你的飞牛账号密码。登录成功后，客户端会保持登录状态，下次打开无需重复登录。

3
在客户端内使用所有应用

文件、相册、Docker 等所有飞牛应用均在客户端内打开，不会外跳到系统浏览器。每个应用以独立窗口运行，可以通过菜单栏或托盘切换。

💡 历史地址会自动记录。输入框右侧的 ▾ 按钮可查看、切换或删除已连接过的服务器，每个服务器的登录状态独立保存。

下载文件到本地

  • 在飞牛文件应用中点下载后，会弹出客户端的「另存为」对话框，选择保存位置后开始下载。
  • 下载进度窗口实时显示文件名、保存路径、进度条、百分比、下载速度、已下载 / 总大小和剩余时间（ETA）。
  • 点进度窗口右上角的 × 不会取消下载，窗口只是隐藏到后台，下载继续进行。
  • 找回后台下载：顶部菜单「下载 → 下载任务」会列出所有正在下载的文件（带实时百分比）和最近 8 条已完成记录；系统托盘右键菜单同样提供"正在下载（N）"和"最近完成的下载"两个子菜单。点击活跃项可调出对应进度窗口，点击已完成项可打开文件所在文件夹。
  • 下载完成后系统通知区会弹出"下载完成"提示，进度窗口自动关闭；点击「打开所在文件夹」会在资源管理器中选中该文件。
  • 取消下载会先本地暂停、等待 1.5 秒再安全断开，不会向 NAS 发送任何删除请求，不影响 NAS 上的原文件。

启动密码 / 一键锁定 / 一键隐藏

  • 在 设置 → 启动密码 中设置 4 位以上密码。密码使用 scrypt + 随机盐哈希存储，不保存明文，并经系统 DPAPI 加密。
  • 设置后，每次启动 FNOS 会弹出玻璃锁屏，只显示密码输入框，输入正确密码才能进入。
  • 锁定 FNOS：菜单或托盘项 / 全局快捷键 Ctrl+Alt+L。
  • 一键隐藏：所有窗口连同托盘图标一起消失，适合临时遮挡屏幕；再次按同一快捷键即可恢复。

忘记启动密码怎么办？

启动密码仅保存在本机、经系统 DPAPI 加密，无法找回明文。忘记密码时按下面步骤重置（不会删除你的 NAS 登录信息与其它设置之外的数据，仅清除启动密码）：

  • 1）先完全退出 FNOS（托盘右键 → 退出；若停在锁屏界面，可在任务管理器里结束 FNOS 进程）。
  • 2）按 Win+R 打开"运行"，输入 %APPDATA%\FNOS 回车，打开配置目录。
  • 3）删除该目录下的 settings.json 文件（可先备份到桌面）。
  • 4）重新打开 FNOS，启动密码即被清除，可进入后到 设置 → 启动密码 重新设置。
说明：删除 settings.json 会同时重置偏好设置（主题、缓存档位、URL 重写等）；NAS 服务器登录历史保存在 servers.json，不受影响。

内置 MPV 播放器（显卡硬解 · 点开即看）

  • 安装包已内置 mpv.exe（GPL 开源），无需另外下载。
  • 自动接管：飞牛影视里遇到网页播放器解不了的视频（HEVC/H.265、10bit、4K、MKV 等），客户端会自动抓取真实视频地址，在页面视频区原位调用内置 MPV 显卡硬解播放，不弹外部窗口；也可在播放页打开 工具 → 用 MPV 打开当前视频（硬解）手动接管。
  • 中文界面：MPV 的控制条（OSC）、右键菜单、对话框均已为中文。鼠标移到画面底部显示控制条，右键弹出菜单（字幕、音轨、画面、播放速度等）。
  • 硬解低占用：默认 d3d11va 显卡硬解 + d3d11 渲染，4K/HDR 更流畅、CPU 占用更低；可在 设置 → MPV 切换硬解方式与缓存档位。
  • 长视频自动续播：点播（MKV/电影）使用的是 NAS 生成的时效签名链接，播放一段时间后续传链接可能过期。MPV 会自动重新获取新链接并从断点继续，无需手动重播；拖动进度条若定位较慢也会自动重新取流并跳到你拖动的位置。
  • 关闭 MPV：点 MPV 画面右上角的 × 即可关闭播放器并回到网页（不会再自动重开）；换台 / 换电影时会自动切换到新节目。
  • 播放日志：MPV 的详细运行日志（HTTP 状态、重定向、断流与重连/重新取流记录）写在 %APPDATA%\FNOS\fnos-mpv.log；客户端诊断日志为 %APPDATA%\FNOS\fnos-diag.log，反馈问题时可一并提供。
  • 如需手动操作，可点击菜单栏 工具 → 系统终端（快捷键 Ctrl+`），会自动打开一个已定位到 MPV 目录的控制台窗口，直接运行 mpv.exe <视频地址> 即可。

内置电视直播（配合 XTE-IPTV）

  • 客户端内置电视直播窗口，同样使用内置 MPV 内核播放，支持 4K 高清直播、HLS(m3u8)/FLV 等流，自动为媒体流注入跨域(CORS)头，换台即播。
  • 直播流长时间运行遇到运营商断流/抖动时，MPV 会自动重连（最多 30 次）并在进程异常时崩溃自愈续播，保持画面不中断。
  • 配合 XTE-IPTV：内置直播的节目源可配合你自建的 XTE-IPTV 工具生成的直播订阅 / 播放列表使用，在直播窗口中填入订阅地址即可加载频道列表与节目单（EPG）。
  • 飞牛影视网页内的直播频道也会自动用 MPV 接管播放。

多窗口与后台运行

  • 在飞牛中打开的每个应用都在独立窗口中运行，可以同时使用多个应用。
  • 点击主窗口关闭按钮时，可选择「隐藏到托盘」（所有窗口继续后台运行，适合下载、同步等长任务）或「退出程序」。
  • 在系统托盘（任务栏右下角）左键单击 FNOS 图标显示所有窗口；右键打开菜单，可切换窗口、查看下载任务、退出程序。
  • 选择「返回 FNOS 主页」时，如果还有其他应用窗口打开，会让你选择是后台保留还是一并关闭。

外网访问与 URL 重写

在 设置 → 应用外网地址（URL 重写规则） 中，可以把内网地址自动替换成外网地址。例如：

  • 匹配：http://192.168.1.10:5666
  • 替换为：https://nas.example.com

这样点应用卡片时会自动用外网地址打开，适合在外网环境下使用。

界面个性化

  • 自动隐藏菜单栏（按 Alt 显示）：设置中开启后，菜单栏平时隐藏，按 Alt 临时呼出，最大化时更清爽。
  • 玻璃标题栏（实验性）：默认关闭，开启后使用 Windows 11 Mica/Acrylic 风格的标题栏。不影响任何现有功能，不喜欢可随时关闭。
  • 主题色：内置蓝、青、紫、粉、绿、橙 6 种标题栏配色。

直播 / 绿屏 / 授权问题

  • 电视直播跨域：客户端自动为 m3u8 / ts / mp4 / mkv / flv / webm 等媒体流注入 CORS 响应头，等效于 KNAS 浏览器插件，飞牛影视的直播频道可直接观看；业务 API 的跨域处理完全透传给 NAS，不做任何改写。
  • 绿屏 / 花屏：移除了导致 ARM / 集显设备绿屏的 COEP / CORP 头，并伪装 User-Agent 为桌面 Chrome，飞牛音乐、飞牛影视登录后不再绿屏。
  • NAS 账号授权无反应：所有 OAuth 弹窗改为在客户端内以独立窗口打开，授权完成后自动回跳，不会再循环登录页。
  • 投屏 / 媒体键：保留 Chromium 原生的 MediaRouter、CastMediaRouteProvider、DialMediaRouteProvider、GlobalMediaControls、HardwareMediaKeyHandling，飞牛影视可正常投屏到 Chromecast / DLNA 设备，系统媒体面板和键盘多媒体键可控。
  • Win7 支持：基于 Electron 22（Chromium 108，最后一个支持 Win7 的版本）打包，Win7 SP1 x64 可安装运行。

常见问题

连接失败怎么办？

  • IP / 域名方式：确认 NAS 已开机、和电脑在同一网络、端口（默认 5666）正确。
  • FN ID 方式：确认 FN ID 拼写正确，电脑能访问外网（fnos.net）。
  • HTTPS 自签证书站点：在弹出的证书确认窗口选择继续即可。

登录状态会失效吗？

不会。每个服务器都有独立的持久化会话分区，Cookie 和本地数据加密保存在本机；关闭主窗口、隐藏到托盘、切换到其他服务器再切回来、或重启电脑后再次打开，该服务器的飞牛账号都会自动保持登录。只有在登录页历史列表里主动删除该服务器，或在飞牛页面里主动登出，才会清除对应服务器的登录状态。

视频播放到一半中断 / 进度条拖不动？

电影/MKV 走的是 NAS 生成的时效签名链接，播放较久后链接可能过期。新版内置 MPV 会自动重新获取链接并从断点续播，拖进度条卡住时也会自动重新取流并跳到目标位置，一般无需操作。若仍异常，可关闭 MPV 后用 工具 → 用 MPV 打开当前视频 重新接管，并把 %APPDATA%\FNOS\fnos-mpv.log 与 fnos-diag.log 反馈给作者。直播频道因分片实时刷新，不受此影响。

如何彻底退出？

托盘右键 → 退出，或在文件菜单里选退出。选「隐藏到托盘」程序仍会在后台运行。

数据保存在哪里？

所有设置和登录信息保存在 %APPDATA%\FNOS，使用系统 DPAPI 加密。卸载程序时不会删除此目录，重新安装后登录数据仍在。

桌面 / 开始菜单图标还是旧的？

安装程序会自动调用 SHChangeNotify 和 ie4uinit -show 刷新 Windows 图标缓存。极少数情况下如果仍未刷新，可在任务管理器里重启「Windows 资源管理器」，或注销重登一次即可。
