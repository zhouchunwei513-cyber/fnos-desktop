外观

使用 macOS 系统材质（NSVisualEffectView），由系统负责模糊与着色。

62%

0% 为实色不透明，越大越透出系统材质。作用于工具栏、查找条与本次设置窗口。

52 pt

红绿灯按钮会随工具栏垂直居中；低于 48pt 时可能贴近边缘。

外观模式

"跟随系统"会随 macOS 外观自动切换浅色/深色。

100%

等同于菜单"显示 → 放大/缩小"（⌘= / ⌘- / ⌘0）。

预览
界面透明度预览

通用

开机登录 macOS 后自动启动 FNOS（可在"系统设置 → 通用 → 登录项"里管理）。

关闭主窗口时不退出应用，图标保留在 Dock 与菜单栏；用 ⌘Q 才真正退出。

启动时回到上次停留的 NAS 页面与窗口位置。

显示/隐藏主窗口。注册成功后会立即生效；被其他应用占用时会提示失败。

恢复默认

恢复默认外观与行为设置；已保存的服务器列表会一并清空。

服务器

支持 IP、IP:端口、域名；不填协议默认 http。保存后主窗口可直接连接。

已保存

    点击列表项可在主窗口打开该服务器。

    安装方式

    macOS 版为免签名分发，无法在应用内静默安装：下载 dmg 后拖入"应用程序"覆盖旧版即可。 若系统提示"已损坏，无法打开"，请在"终端"执行：

    xattr -dr com.apple.quarantine /Applications/FNOS.app
